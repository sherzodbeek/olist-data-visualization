2. Before Visualization: Data Preparation and Analysis

Before creating the charts, complete the following tasks for each scenario and bring your files to class.

Identify the scenario: Describe the real-world problem or situation you want to analyze using your project data.

Identify the features: List the selected columns/features and specify their data types, such as integer, float, categorical, Boolean, or date/time.

Identify the scale, range, and domain: Specify the possible or observed values of each selected feature, including units where applicable.

Justify your chart selection: Explain why the selected chart is appropriate for the scenario and what information it will reveal.

3. Visualization and Python Implementation

For each of the nine charts, complete the following tasks:

Select the appropriate Python library: Choose a suitable library, such as Matplotlib, Seaborn, or Plotly, depending on the visualization requirements.

Write efficient Python code: Implement the chart using your own project data. Ensure that the code runs correctly and produces the intended visualization.

Compare multiple features or groups: At least two charts must compare more than one branch, category, group, or feature within the same chart.

Use appropriate visual design: Include meaningful chart titles, clear axis labels, appropriate colors, readable font sizes, legends where necessary, and suitable figure dimensions.

Interpret the results: Briefly explain the main patterns, comparisons, distributions, or insights revealed by each chart.
